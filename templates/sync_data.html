Panduan Sinkronisasi
Push (Lokal → Cloud)
  • Gunakan saat Anda yakin data lokal sudah benar
  • Data di Cloud akan DITIMPA oleh data lokal
  • Cocok untuk update dari kantor pusat ke cloud
Pull (Cloud → Lokal)
  • Gunakan saat Anda ingin update data lokal dari cloud
  • Data di lokal akan DITIMPA oleh data cloud
  • Cocok untuk download data terbaru ke komputer
Sync Gabungan
  • Gunakan untuk menggabungkan data dari 2 sumber
  • Data TIDAK ditimpa, hanya data baru yang ditambahkan
  • Cocok untuk merge data dari beberapa lokasi
